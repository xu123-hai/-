# 面向人机运动性能评估的网页端参数匹配生成器

> 课程设计项目仓库 —— 智造24.2 徐海烽

## 项目简介

本项目开发一套网页版人机运动性能测试与参数匹配原型系统。通过模拟人机交互运动测试，
采集用户手部运动、定位追踪、快速转向等运动行为数据；结合使用者操作习惯、硬件参数，
通过数据分析算法输出适配个人操作特性的控制参数。系统内置定点定位、动态追踪、快速切换、
物理标定等测试单元，为**纯前端单 HTML 网页**，无需后端，浏览器打开即可完成测试与参数生成。

## 运行方式（网页原型）

直接用浏览器（Chrome / Edge）打开仓库根目录的 `index.html` 即可运行，无需安装、无需后端：

1. 在左侧录入测试者编号、鼠标 DPI、握鼠习惯、速度/精度倾向、测试轮数
2. 在中间选择测试项目（定点定位 / 动态追踪 / 快速切换 / 物理标定），点击「开始测试」
3. 完成各项目测试后，右侧自动生成测试统计与个性化控制参数
4. 支持一键复制参数、重置数据、导出测试数据 CSV（格式与 `/data` 样例一致）

网页原型实现要点：Canvas 虚拟仿真与碰撞检测、时间戳倒计时（60FPS）、
四类运动测试数据实时采集、加权参数匹配算法（速度/精度分项得分 + 习惯权重修正 →
灵敏度/加速度/平滑/响应阈值映射）、物理位移-虚拟转动标定换算（cm/360 等效）。

## 数据来源

本课程设计数据为**自建实测数据**，由网页端在运行时实时采集生成，数据量小，
已按课程设计要求**直接提交到仓库 `/data` 目录**（不涉及公开数据集，亦无敏感数据）。

- 采集方式：使用者在浏览器内完成虚拟运动测试，系统实时采集运动行为原始数据，可导出 CSV
- 样例数据：`data/raw/sample_test_data.csv` 为自建样例数据，由
  `scripts/generate_sample_data.py` 模拟生成（可复现），格式与网页端导出一致
- 详细说明见 [`data/README.md`](data/README.md)

> 若后续形成较大规模真实采集数据集，将按要求在 Hugging Face / ModelScope 开源并注明为自建数据集。

## 数据预处理

预处理程序：`scripts/preprocess.py`（Python 标准库实现）

流程：加载原始数据 → 清洗（剔除缺失/非法值）→ 去离群（均值±3σ，按测试类型×指标分组）
→ 派生指标（命中率 hit_rate）→ 统计聚合（均值/标准差/中位数）→ 输出预处理产物。

运行方式：

```bash
cd scripts
python generate_sample_data.py   # （可选）重新生成样例原始数据
python preprocess.py             # 执行预处理
```

预处理产物位于 `data/processed/`（清洗明细、统计汇总、`index.json` 索引），
与 `方案设计.md` 3.5 节「数据预处理算法」一致；该算法已同步内嵌至网页原型
`index.html` 的 JavaScript 中（测试数据清洗、去离群、统计聚合）。
